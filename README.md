# Jobtrack
Gestor personal de candidaturas de empleo con tablero kanban, seguimiento de fases y estadísticas. Desarrollado con Spring Boot + JPA y Vue/React, aplicando Spec-Driven Development con GitHub Spec Kit.

## Desarrollo
Cada cambio de funcionalidad debe comenzar con una especificación clara y criterios de aceptación. El proyecto sigue la constitución de gobernanza del repositorio y los flujos de Spec Kit para mantener calidad, trazabilidad y coherencia con el tablero de candidaturas.
